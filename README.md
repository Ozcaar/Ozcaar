### 🌟 Featured Projects

#### 🟣 InviRtual
A full-featured digital invitations platform designed for an elegant and intuitive user experience.  
Built with a **modular Spring Boot backend** (API-first, DTOs, mappers, Swagger docs, Dockerized PostgreSQL) and a **Nuxt 4 frontend** (Pinia, TailwindCSS, DaisyUI, dynamic builder UI).  
Focuses on clean architecture, reusable components, and seamless integration between modules.

#### 🟩 POS & Business Tools
A suite of tools for small businesses — from sales and inventory management to role-based authentication and analytics.  
Developed with **ASP.NET Core**, **EF Core**, and **Vue**, emphasizing scalability and RESTful API design.

#### 💜 Aromalia
An e-commerce ecosystem prototype including backend services and a C# desktop client for administration.  
Built to explore microservice concepts and interface integration with APIs, using **Java**, **Spring Boot**, and **.NET**.
